ICEBREAKER v1.3.0 — OFFICIAL + MANUAL API SOURCES

OFFICIAL API SETUP
1. Open the .env file in the extracted extension folder.
2. Paste two Groq keys and two OpenRouter keys into the four provided slots.
3. Double-click scripts/api/Build-Official-Keys.bat.
4. The script generates official-api-keys.js for the extension.

INSTALL THE EXTENSION
1. Open chrome://extensions.
2. Enable Developer mode.
3. Remove or disable the older unpacked IceBreaker version.
4. Click Load unpacked.
5. Select this extracted folder containing manifest.json.
6. Confirm version 1.3.0.
7. Refresh all open LinkedIn tabs.

API OPTIONS
- Official API: Groq and OpenRouter use their two-key rotating pools. A retryable failure on one official key falls back to the other key.
- Manual API: paste one gsk_ Groq key or sk-or- OpenRouter key in Settings. IceBreaker detects the provider automatically.
- Side panel: after a manual key is saved, a My Groq or My OpenRouter button appears with the matching provider logo.
- Ollama: remains local and does not use either cloud API source mode.

AUTOPILOT
1. Open IceBreaker Settings > Autopilot.
2. Upload the AI Resume.
3. Choose the role, draft limit, pacing, Vibe, and length.
4. Save Autopilot settings.
5. Open a LinkedIn people/search-results page.
6. Open IceBreaker and click Start Autopilot.

AUTOPILOT NEVER CLICKS SEND. You review and manually send every prepared draft.

SECURITY WARNING
Keys bundled in an unpacked or published Chrome extension can be extracted. For a public release, use a protected backend proxy instead of shipping provider keys to users.
