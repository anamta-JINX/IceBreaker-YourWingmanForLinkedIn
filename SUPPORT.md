# Support

Before opening an issue:

1. Reload IceBreaker from `chrome://extensions`.
2. Refresh LinkedIn.
3. Confirm the selected provider and model.
4. Test the provider from IceBreaker Settings.
5. Check the service-worker console for the complete error.
6. Remove API keys and personal information from screenshots and logs.

Use the bug-report template for reproducible problems and the feature-request template for new ideas.
